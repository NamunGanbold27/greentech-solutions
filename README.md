# GreenTech Solutions

A simple front end website that presents a sustainable energy brand concept. The project showcases clean energy products, interactive elements, and a user friendly layout.

## Overview

GreenTech Solutions is a fictional company site focused on solar, wind, and home battery technology. The site demonstrates basic front end development skills through HTML, CSS, and JavaScript. It includes sticky navigation, scroll based link highlighting, interactive product cards, dynamic form validation, and a clean visual layout.

## Features

• Sticky navigation that becomes fixed when scrolling  
• Automatic highlighting of the active section link based on scroll position  
• Interactive introduction text that can be shown or hidden  
• Product cards with expandable detail sections  
• Newsletter form with client side email validation  
• Dynamic footer year  
• Fully responsive styling  

## How to run

Open `index.html` in any web browser.  
No server or build tools are required.
